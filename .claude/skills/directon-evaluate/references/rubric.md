# DIRECT:ON 평가 기준

2026년 11월 20일 기준 공개 안내. 공식 점수는 대회 운영진의 평가 결과를 따른다. 실험 결과에는 사용한 입력, 채점 근거, 공개 기준에 대한 해석을 함께 기록한다. [평가 기준](https://direct-on.vercel.app/eval.html)

## 시스템 평가

100점 척도에서 응대 50%, 함수 호출 20%, 속도 30%를 합산한다. 시상은 사용자 경험 50점, 시스템 20점, 발표와 질의응답 20점, 최종 기획서 10점을 합한다. 시상에 반영하는 시스템 점수는 100점 척도의 시스템 점수를 5로 나눈 값이다. [시스템 평가와 시상 기준](https://direct-on.vercel.app/eval.html)

| 항목 | 확인할 내용 |
| --- | --- |
| 응대 | 고객 의도와 대화 맥락에 맞게 답하고 상담 매뉴얼과 가격·정책·절차·조회 결과 등 사실을 정확히 안내했는지 확인한다. 판정 계수는 정답 1.0, 대체로 적절한 답변 0.7, 오답 0이다. 경계 사례는 정답과 매뉴얼을 근거로 판단한다. |
| 함수 호출 | 필요한 호출을 적절한 시점에 했는지, 불필요한 호출이 없는지, 인자와 식별자가 정확한지 확인한다. 세부 판정의 공식 집계 방법은 운영진 평가에 따른다. |
| 속도 | 고객 발화가 실제로 끝난 시점부터 첫 소리까지 잰다. 안내용 짧은 선응답도 첫 소리에 포함한다. 실제 함수 호출이 있는 경우 함수 응답 이후 본답변이 시작되기까지 걸린 시간도 잰다. 두 시간을 각각 아래 표로 점수화한 뒤 평균한다. |

응답이 발화 종료보다 빠르거나 소리가 없거나 연결에 실패하면 해당 문항의 속도는 0점이다. `turn.end`가 없거나 발화 종료 후 25초를 넘긴 경우 규격 위반으로 표시한다. `after_tool_sound`는 로컬 측정기의 함수 응답 이후 첫 유성 프레임 지표다. 본답변 시작을 알려 주는 명시적 기록이 없으면 이 값을 대리 측정값으로 표시한다. [평가 기준](https://direct-on.vercel.app/eval.html) · [통신 규격](https://direct-on.vercel.app/open.html)

| 2.0 초과 2.5 이하 | 80 |

## 정성 평가 체크리스트

연습용 채점표가 필요하면 확인한 증거를 기준으로 항목당 충족 2, 부분 충족 1, 실패 0을 준다. 근거가 부족한 항목은 미평가로 남기고 항목별 증거와 개수를 표시한다. 연습 점수를 환산할 경우 같은 부문 안에서 항목에 동일한 비중을 적용한다. 미평가가 있다면 확인한 항목의 점수와 평가 범위를 함께 표시하고 그 부문의 시상 배점 환산은 보류한다. 이 척도와 동일 비중은 모의 심사용 가정이다. [평가 기준](https://direct-on.vercel.app/eval.html)

## 운영 규격 체크리스트

- 평가기에서 WebSocket 상담원 서버와 HTTP 모의 함수 서버에 접속할 수 있어야 한다. 네 개의 문항을 동시에 처리할 수 있는지 점검한다.
- 연결당 한 문항을 받고 `session.start` 후 고객 음성을 처리한다. 공개 입력 규격은 16kHz 단일 채널 16비트 PCM으로 20ms당 640바이트다. 응답은 같은 형식의 음성과 `turn.end`를 보낸다.
- 함수 요청은 `session.start.tools_url`로 향해야 하며 `X-Session-Id`로 평가 세션을 연결한다.
- 대회 중에는 공개 범위에서 정한 제공 데이터를 사용한다. 실제 시험 음성을 저장하거나 반출하지 않는다. 점수 재현에는 자체 합성 음성과 저장이 허용된 로그를 사용한다.
